# Guide d'utilisation : Skill `expert-compta-syscohada`

## 1. Ce que fait ce skill
Ce skill est dédié exclusivement à la **production comptable opérationnelle et au conseil de gestion** selon le référentiel **SYSCOHADA révisé**. Il passe les écritures comptables exactes (issues de `references/plan-comptable-syscohada-revise.csv`), vérifie les pièces justificatives et la TVA, et calcule l'impact sur les Soldes Intermédiaires de Gestion (VA, EBE, CAFG, BFE).

## 2. Mots-clés déclencheurs
* `comptabilise`, `passe l'écriture`, `journal`, `facture`, `arrêté des comptes`, `clôture`, `bilan`, `compte de résultat`, `SIG`, `CAFG`, `BFE`, `TVA`, `amortissement`, `cession`.

## 3. Exemples de questions
* « Comptabilise cette facture d'acquisition d'un matériel industriel avec frais de transport, installation et TVA récupérable selon le SYSCOHADA révisé. »
* « Passe les écritures de cession de ce véhicule amorti sur 5 ans et vendu en cours d'exercice. »
